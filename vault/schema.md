# 知识库 Schema

## 我关注的顶层主题
- AI技术
- 游戏行业
- 产品与战略
- 技术工程
- 其他

## 分类粒度
最多三层文件夹：顶层 / 子领域 / 具体主题。
不确定时归到子领域层，宁浅勿乱建深层目录。

## 子领域示例（可随时手动扩充）
- AI技术: 大模型 / Agent框架 / 提示工程 / 多模态 / 训练与微调
- 游戏行业: 游戏设计 / 商业化 / AI+游戏 / 行业动态
- 产品与战略: 方法论 / 竞品分析 / 用户增长 / 商业模式
- 技术工程: 前端 / 后端 / 架构 / DevOps / 数据库

## 主题页结构
每页固定包含：
- ## 核心观点（该主题的关键结论）
- ## 关键证据（带原帖链接的支撑材料）
- ## 关联主题（双向链接列表）
- ## 待澄清（矛盾或不确定之处）

## 双链规则
仅在以下情况建链：
1. 同一论点的不同证据来源
2. 互为因果关系
3. 观点对立/矛盾
避免过度连接——不是所有同领域的主题都需要链接。

## 矛盾处理
发现新内容与已有结论冲突时：
- 标记到"待澄清"区域
- 绝不静默覆盖旧结论
- 保留双方论据供人工判断

## 分类指导
- 如果一篇文章横跨多个主题，归到最核心的那个，其余通过双链关联
- 新闻/动态类内容归到对应行业子领域
- 教程/方法论类内容归到对应技术子领域
- 观点/评论类内容根据讨论的核心对象归类
